Lost access? Reset the password from the server terminal

If you don't know the current admin credentials, run this on the server to set a new password without logging in:

Docker

docker compose exec mailserver env RESET_USER=admin RESET_PASS=newpassword mailserver reset-password

Bare metal / systemd

RESET_USER=admin RESET_PASS=newpassword mailserver reset-password

Replace admin and newpassword with the username and new password you want. Then log in again with the new password.
